## 一、技术栈

| 层 | 技术 |
|:---|:---|
| 框架 | Vue 3（Composition API + Options API） |
| 构建 | Vite 8 |

## 三、组件分层

### 3.1 原子（atoms）
最小可复用单元，无业务语义。

### 3.2 分子（molecules）
原子组合，有独立业务语义，可在不同有机体和页面中复用。

### 3.3 有机体（organisms）
完整功能区块，由分子拼装而成，通常有专属业务逻辑。

### 3.4 布局（layouts）
页面骨架。`MainLayout` 包含：Navbar（顶） + `<router-view />`（中） + PlayerBar（底） + Footer（底）。

### 3.5 页面（views）
路由入口，负责注入数据给有机体。

## 四、路由表

### 前台路由

| 路由 | 组件 | 说明 |
|:---|:---|:---|
| `/` | Home | 首页，Hero + 最新专辑网格 + 热门社团 |
| `/album/:id` | AlbumDetail | 专辑详情（左右布局） |

| `/cart` | CartView | 购物车：商品列表 + 结算面板 |

### 后台管理路由（Pro/Staff）

| 路由 | 组件 | 说明 |
|:---|:---|:---|
| `/admin` | Dashboard | 数据透视页 |
| `/admin/albums` | AlbumList | 专辑管理列表 |
| `/admin/albums/create` | AlbumForm | 新增专辑 |
| `/admin/albums/:id/edit` | AlbumForm | 编辑专辑（含曲目管理） |
| `/admin/circles` | CircleList | 社团管理列表（Staff） |
| `/admin/circles/:id` | CircleDetail | 社团详情/成员管理（Staff） |

| `/admin/comments` | CommentList | 评论管理列表 |
| `/:pathMatch(.*)*` | NotFound | 404 页面 |

## 五、Pinia Store 设计

### 5.1 user store

```js
// stores/user.js - Composition API
{
  user: ref(null),           // 用户信息
  isLoggedIn: computed,      // 是否登录
  doRegister(form),          // 注册
  doLogin(form),             // 登录
  doLogout(),                // 登出
  init()                     // 初始化（fetchMe）
}
```

### 5.2 player store

```js
// stores/player.js - Composition API
{
  playlist: ref([]),         // 播放列表
  current_index: ref(0),     // 当前曲目索引
  is_playing: ref(false),    // 播放状态
  is_expanded: ref(false),   // 展开状态
  current_track: computed,   // 当前曲目
  // localStorage 持久化: indietracks_player
  playAlbumTracks(tracks, startIndex),
  addAlbumTracks(tracks),
  jumpToTrack(index),
  prev(), next(),
  reorder(from, to),
  removeTrack(index),
  clearPlaylist()
}
```

### 5.3 favorite store

```js
// stores/favorite.js - Options API
{
  favoriteAlbumIds: [],      // 收藏的专辑 ID 列表
  isFavorite(albumId),       // 检查是否收藏
  toggleFavorite(albumId),   // 切换收藏
  check(albumId),            // 检查单个收藏状态
  loadAll()                  // 加载所有收藏
}
```

## 六、设计风格

暗黑直角风格，参考 dizzylab.net：
- 背景 `#0a0a0a`，强调色 `#ff6b6b`，hover 态 `#ff8787`
- 边框 `#222` / `#333`，卡片背景 `#1a1a1a`
- 字体：Inter / PingFang SC / Microsoft YaHei
- 无圆角（border-radius: 0 或极小值）

### 按钮风格

- **播放按钮**：描边风格（`border: 1px solid accent`），hover 时填充
- **播放中指示器**：竖条动画（3 个竖条交替伸缩）
- **播放器控制**：描边圆形播放按钮，hover 时填充

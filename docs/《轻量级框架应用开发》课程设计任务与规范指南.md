
# 《轻量级框架应用开发》课程设计任务与规范指南

## 一、 课程基本信息
- **开课单位**：广州软件学院 - 软件与人工智能学院
- **课程名称**：轻量级框架应用开发
- **适用年级**：2026届

## 二、 选题与任务要求

### 1. 选题方向（二选一）
- **题目一：员工信息管理系统**
  - **业务场景**：基于MySQL数据库中的 `employee` 表进行数据管理。
  - **数据表结构**：包含字段 `emp_id`（员工ID）, `emp_name`（姓名）, `emp_gender`（性别）, `emp_dept`（部门）, `emp_birth`（生日）。
- **题目二：自拟题目（xxx系统）**
  - **要求**：自拟题目必须在第16周提交分组名单时进行备注说明。

### 2. 核心技术栈要求
- **后端框架**：Spring Boot + SpringMVC
- **持久层框架**：MyBatis 或 MyBatis-Plus
- **数据库**：MySQL
- **接口规范**：必须实现 **Restful 风格** 的 WebAPI 接口。

### 3. 必做模块与代码架构规范
项目必须严格遵循三层架构进行开发，具体代码实现要求如下：
1. **配置层**：在项目中引入 MySQL、MyBatis 相关依赖，并在 `application.yaml` (或 `.properties`) 中完成数据库及框架的相关配置。
2. **数据持久层（Mapper/DAO）**：编写持久层代码，实现对应数据表的增（Create）、删（Delete）、改（Update）、查（Retrieve）操作方法。
3. **业务逻辑层（Service）**：编写业务层代码，调用数据持久层方法，封装并实现增、删、改、查的业务接口。
4. **控制器层（Controller）**：编写控制器层请求处理方法，调用业务层接口，对外暴露 Restful 风格的增、删、改、查 WebAPI。

## 三、 分组与答辩规范

### 1. 分组要求
- **人数限制**：每组 **不超过 3 人**。
- **分工要求**：小组成员必须有明确的责任划分（如：数据持久层代码、业务层代码、控制器层代码、测试代码等）。
- **截止时间**：**第 16 周小课**前完成分组，并将名单（含自拟题目备注）汇总给任课教师。

### 2. 答辩要求
- **答辩时间**：**第 18 周小课**。
- **时长限制**：每组展示时间 **不超过 10 分钟**。
- **展示内容清单**：
  1. 介绍小组成员及其具体分工。
  2. 项目运行实物演示。
  3. 项目后端架构讲解。
  4. 项目测试情况讲解。
  5. 回答老师现场提问。

## 四、 交付与提交规范

### 1. 提交时间与路径
- **提交时间**：**第 18 周**。
- **提交路径**：按照任课教师要求，提交至专门的“课程设计”目录下。

### 2. 提交物清单及打包规范
每组需提交以下两项内容：

#### A. 代码压缩包
包含前端项目（如有）和后端项目，**必须严格遵守以下清理规范**：
- **前端项目**：打包前 **务必删除 `node_modules` 目录**。
- **后端项目**：打包前 **务必删除 `target` 目录**，或在项目根目录执行 `mvn clean` 命令清理编译产物。

#### B. 设计与实现文档（每组 1 份）
文档必须包含以下核心章节：
1. **团队信息**：小组成员名单及其详细分工。
2. **前端架构**：前端技术架构说明及核心代码介绍（如有前端）。
3. **后端架构**：后端技术架构说明及核心代码介绍。
4. **运行截图**：项目核心功能的运行结果截图（**重点要求，必须包含**）。
5. **心得体会**：团队成员的课程设计总结与心得体会。

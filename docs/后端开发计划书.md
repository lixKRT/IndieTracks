## 三、关键设计决策

### 3.1 字段命名

- Entity 字段直接使用 snake_case（与数据库列名一致）
- Jackson 默认原样输出，无需额外配置 `PropertyNamingStrategy`
- MyBatis-Plus 默认 `map-underscore-to-camel-case` 对同名字段无影响

### 3.2 DTO 设计

Entity 和 API 返回分离。JOIN 查询结果映射到 DTO，Entity 保持和表一一对应。

**AlbumListItem**（列表接口返回）：
```
album_id, title, circle_id, circle_name, circle_logo_url, cover_url,
info_title, info_content, price, publish_date, tags[], track_count
```

**AlbumDetail**（详情接口返回）：
```
album_id, title, circle{circle_id, name, logo_url}, cover_url, price, publish_date,
info_title, info_content, tags[{tag_id, name}],
tracks[{file_id, file_name, track_length, sort_order, file_type, preview_url}],
comments[{comment_id, user_id, username, avatar_url, content, created_at}]
```

**CircleListItem**（社团列表返回）：
```
circle_id, name, logo_url, description, album_count, member_count,
representative_tags[], preview_albums[{album_id, title, cover_url, tags[]}]
```

**CircleDetail**（社团详情返回）：
```
circle_id, name, logo_url, description, albums[...],
members[{user_id, username, avatar_url, user_role}]
```

### 3.3 URL 构造

MinIO 资源通过 `minio.url-prefix` 配置：
- 开发环境：`http://localhost:9000`（直接访问 MinIO）
- 生产环境：`/minio`（Nginx 代理）

### 3.4 分页

使用 MyBatis-Plus 的 `IPage<T>` 分页插件。返回格式统一：
```json
{
  "data": [...],
  "total": 100,
  "page": 1,
  "page_size": 12
}
```

## 四、接口设计

|---|---|---|
| GET | `/api/albums?page=1&page_size=12&tag=电子&search=冬日&price=free&sort=publish_date_desc` | 专辑列表（分页+筛选） |

## 五、配置文件

### 5.1 application.properties（开发环境）

```properties
server.port=8080
spring.datasource.url=jdbc:postgresql://localhost:5432/indietracks
spring.datasource.username=postgres
spring.datasource.password=postgres
spring.datasource.driver-class-name=org.postgresql.Driver
mybatis-plus.configuration.map-underscore-to-camel-case=false
mybatis-plus.mapper-locations=classpath:mapper/*.xml
jwt.secret=indietracks-secret-key-must-be-at-least-256-bits-long-for-hs256
jwt.expiration=604800
jwt.remember-me-expiration=2592000
minio.endpoint=http://localhost:9000
minio.access-key=minioadmin
minio.secret-key=minioadmin
minio.bucket=indietracks
minio.url-prefix=${minio.endpoint}
```

### 5.2 application-prod.properties（生产环境）

使用环境变量占位符：
```properties
spring.datasource.url=jdbc:postgresql://${DB_HOST:localhost}:${DB_PORT:5432}/${DB_NAME:indietracks}
spring.datasource.username=${DB_USER:postgres}
spring.datasource.password=${DB_PASS:postgres}
jwt.secret=${JWT_SECRET:change-me-in-production}
minio.endpoint=${MINIO_ENDPOINT:http://localhost:9000}
minio.access-key=${MINIO_ACCESS_KEY:minioadmin}
minio.secret-key=${MINIO_SECRET_KEY:minioadmin}
minio.bucket=${MINIO_BUCKET:indietracks}
minio.url-prefix=/minio
```

## 三、关键设计决策

### 3.1 字段命名

- Entity 字段直接使用 snake_case（与数据库列名一致）
- Jackson 默认原样输出，无需额外配置 `PropertyNamingStrategy`
- MyBatis-Plus 默认 `map-underscore-to-camel-case` 对同名字段无影响

### 3.2 DTO 设计

Entity 和 API 返回分离。JOIN 查询结果映射到 DTO，Entity 保持和表一一对应。

**AlbumListItem**（列表接口返回）：
```
album_id, title, circle_name, cover_url, price, publish_date, tags[], track_count
```

**AlbumDetail**（详情接口返回）：
```
album_id, title, circle{circle_id, name, logo_url}, cover_url, price, publish_date,
info_title, info_content, tags[{tag_id, name}], tracks[{file_id, file_name, track_length, sort_order, file_type, preview_url}],
comments[{comment_id, username, avatar_url, content, created_at}]
```

**CircleListItem**（社团列表返回）：
```
circle_id, name, logo_url, description, album_count, member_count
```

**CircleDetail**（社团详情返回）：
```
circle_id, name, logo_url, description, albums[...], members[{user_id, username, avatar_url, user_role}]
```

### 3.3 音频播放

后端集成 MinIO SDK，为每个曲目生成预签名 URL（有效期可配置，默认 7 天）。

`AlbumDetail.tracks[].preview_url` = MinIO 预签名 URL，前端 `<audio>` 标签直接播放。

### 3.4 分页

使用 MyBatis-Plus 的 `IPage<T>` 分页插件。返回格式统一：
```json
{
  "data": [...],
  "total": 100,
  "page": 1,
  "page_size": 12
}
```

## 四、接口设计

### 4.1 专辑列表

```
GET /api/albums?page=1&page_size=12&tag=电子&search=冬日&price=free&sort=publish_date_desc
```

**查询逻辑**：
- 主查询：`albums` 表分页
- JOIN：`album_circles → circles`（取 circle_name）
- JOIN：`album_tags → tags`（取标签名数组）
- 子查询：`COUNT(work_files)` 取 track_count
- 筛选：tag（JOIN album_tags）、search（LIKE title / circle_name）、price（=0 / >0）
- 排序：publish_date / price，支持 asc / desc

**实现方式**：MyBatis XML 手写 JOIN SQL，一次查询出所有字段。

### 4.2 专辑详情

```
GET /api/albums/{id}
```

**查询逻辑**：
1. 查专辑基本信息 + 所属社团（JOIN album_circles → circles）
2. 查标签列表（JOIN album_tags → tags）
3. 查曲目列表（work_files WHERE album_id），生成 MinIO 预签名 URL
4. 查评论列表（comments JOIN users），取 username + avatar_url

**实现方式**：Service 层多次查询拼装，因为四个子查询结构差异大。

### 4.3 社团列表

```
GET /api/circles
```

**查询逻辑**：
- 主查询：`circles` 表
- 子查询：`COUNT(album_circles)` 取 album_count
- `member_count` 直接读 circles 表字段

### 4.4 社团详情

```
GET /api/circles/{id}
```

**查询逻辑**：
1. 查社团基本信息
2. 查该社团所有专辑（JOIN album_circles → albums）
3. 查成员列表（JOIN user_circles → users）

### 4.5 标签列表

```
GET /api/tags
```

简单查询 `tags` 表全量。

### 4.6 用户详情

```
GET /api/users/{id}
```

简单查询 `users` 表，返回 user_id / username / avatar_url / user_role。

### 4.7 收藏

```
GET  /api/favorites              # 获取收藏列表
POST /api/favorites/{albumId}    # 添加收藏
DELETE /api/favorites/{albumId}  # 取消收藏
GET  /api/favorites/{albumId}/status  # 检查收藏状态
```

### 4.8 购买

```
GET  /api/purchases              # 获取已购专辑列表
POST /api/purchases/{albumId}    # 购买专辑（模拟支付延迟 2 秒）
GET  /api/purchases/{albumId}/status  # 检查是否已购
```

### 4.9 购物车

```
GET    /api/cart                 # 获取购物车列表
POST   /api/cart/{albumId}      # 加入购物车
DELETE /api/cart/{albumId}      # 移除购物车
GET    /api/cart/count          # 获取购物车数量
POST   /api/cart/checkout       # 批量结算（body: { album_ids: [...] })
```

## 五、配置文件

### 5.1 application.properties

```properties
# 服务端口
server.port=8080

# PostgreSQL
spring.datasource.url=jdbc:postgresql://localhost:5432/indietracks
spring.datasource.username=postgres
spring.datasource.password=${DB_PASSWORD}
spring.datasource.driver-class-name=org.postgresql.Driver

# MyBatis-Plus
mybatis-plus.configuration.map-underscore-to-camel-case=true
mybatis-plus.mapper-locations=classpath:mapper/*.xml

# MinIO
minio.endpoint=http://localhost:9000
minio.access-key=${MINIO_ACCESS_KEY}
minio.secret-key=${MINIO_SECRET_KEY}
minio.bucket=indietracks
minio.presigned-expiry=604800
```

### 5.2 依赖（pom.xml 变更）

需新增依赖：
```xml
<!-- MyBatis-Plus -->
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-spring-boot3-starter</artifactId>
    <version>3.5.7</version>
</dependency>

<!-- MinIO SDK -->
<dependency>
    <groupId>io.minio</groupId>
    <artifactId>minio</artifactId>
    <version>8.5.12</version>
</dependency>
```

需移除依赖：
```xml
<!-- spring-boot-starter-data-jpa（替换为 MyBatis-Plus） -->
```

## 七、前端联调方案

### 7.1 前端改造

1. 新建 `frontend/src/api/request.js`：Axios 实例，baseURL = `/api`
2. 逐页面替换 `import { fetchAlbums } from './mock.js'` → `import { fetchAlbums } from './request.js'`
3. `vite.config.js` 添加 proxy：
   ```js
   server: {
     proxy: {
       '/api': 'http://localhost:8080'
     }
   }
   ```

### 7.2 字段对齐检查

前端 mock.js 中需要修改的字段：
- `duration` → `track_length`（曲目时长）
- 社团列表删除 `representative_tags`、`latest_album_date`、`preview_albums`
- 专辑详情 tracks 增加 `preview_url`（MinIO 预签名链接）

## 八、部署方案

### 8.1 开发环境

- 前端：`npm run dev`（localhost:5173）
- 后端：`./mvnw spring-boot:run`（localhost:8080）
- 数据库：PostgreSQL（localhost:5432）
- MinIO：localhost:9000

### 8.2 生产环境

- Nginx 反向代理
  - `/` → 前端 build 静态文件
  - `/api` → 后端 Spring Boot
- 前端 `npm run build` 产出放到 Nginx 静态目录
- 后端以 jar 包运行
